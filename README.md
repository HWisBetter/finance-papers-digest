# finance-papers-digest

A personal, daily-updated digest of recent finance research with AI summaries.

**🌐 Live site**: https://hwisbetter.github.io/finance-papers-digest/

## Coverage

- **Journals**: JF · JFE · RFS · JFQA · JAR · MS
- **Working papers**: NBER · selected SSRN preprints from a curated list of authors

## Features

- AI-generated Chinese summaries for every paper
- Semantic search (desktop) + keyword search (mobile fallback)
- Author-level pages and a data-driven activity leaderboard
- Daily auto-refresh, monthly citation update

## Tech

Static site (Jinja2 + GitHub Pages) · Python pipeline · DeepSeek for summarization · OpenAlex / Semantic Scholar for metadata
